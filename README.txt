For Alikseniia — one-page love letter website
================================================

To view:
  Open index.html in a modern web browser.

To publish it:
  Upload the entire contents of this folder (index.html and assets/)
  to your preferred static web host (e.g. Netlify, GitHub Pages, or Vercel).
  All images and the sample song are stored inside the assets folder.

Music:
  "Always, Us" is an original instrumental demo included with this website.
  Visitors must press Play; browsers generally block autoplay with sound.
  Click "Choose your own song" to play a song stored on your device.
  That selection stays only in the local browser session.
  To replace the site's default song for everyone, replace
  assets/always-us.mp3 and adjust the song title in index.html.

A completely standalone version is also provided separately as
love-letter-standalone.html. It has embedded photos and audio,
so it can be opened on its own without an assets folder.
