For Alikseniia — one-page love letter website
================================================

To view:
  Open index.html in a modern web browser.

To publish:
  Upload the entire contents of this folder (index.html and assets/)
  to a static hosting service such as Netlify or GitHub Pages.
  Keep the assets folder alongside index.html.

Music:
  The included song, "Wonderful Tonight," is the default soundtrack.
  The page tries to play it automatically with sound on opening.
  Modern browsers often prevent autoplay with sound until the first user
  interaction. In that case, a small "Play our song" prompt appears, and
  tapping elsewhere on the letter will also start the music.
  Playback can then be paused, resumed, sought, or muted in the player.

  "Change song" lets someone pick a different local audio file while the
  webpage is open; this does not change the song saved on the website.

  To change the permanent soundtrack later, replace
  assets/wonderful-tonight.mp3 with another MP3 and edit the track title.

Standalone edition:
  The separate love-letter-standalone.html embeds photos and song in one
  file. It can be opened directly without an assets folder.

Note: if you publish this webpage publicly, ensure you have permission
for the music you distribute on it.
